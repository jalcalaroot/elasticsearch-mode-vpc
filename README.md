# elastic-search AWS
Para el despliegue de elastic-search AWS  debe contar con lo siguiente:
access_key: ejemplo= <AWS_ACCESS_KEY_ID>
secret_key: ejemplo= <AWS_SECRET_ACCESS_KEY>
region:     ejemplo= us-east-1 (aws virginia) / eu-west-1 (aws irlanda)
elastic_search_name: ejemplo= mielastic
subnet_1: ejemplo= subnet-0123456789abcdef0
vpc_id: ejemplo= vpc-0123456789abcdef0
